# UI-SPEC — PawonBoga

## Halaman
1. Katalog: grid kartu produk (nama, harga, kategori, tombol "Pesan via WhatsApp"), ada kolom pencarian dan filter kategori.
2. Dashboard: tabel daftar produk dengan tombol Ubah dan Hapus, form tambah/ubah produk, tombol Import dan Export JSON.

## Navigasi
Header dengan dua menu: Katalog dan Dashboard.

## Gaya
- Tema hangat (warna dasar krem, aksen oranye/cokelat) sesuai nuansa kuliner.
- Responsif: nyaman dibuka di HP maupun laptop.

## Kondisi khusus
- Data kosong: tampilkan pesan "Belum ada produk".
- Input tidak valid: tampilkan pesan error di bawah field.
